        Google Drive 연결 설정

        Google Drive를 쓰려면 Google에서 무료로 발급하는 OAuth 클라이언트 ID가 한 번 필요합니다.

        1. Google Cloud Console에서 프로젝트를 만듭니다.
        2. “API 및 서비스 → 라이브러리”에서 Google Drive API를 사용 설정합니다.
        3. “OAuth 동의 화면”(Google 인증 플랫폼)을 외부로 구성하고, 테스트 사용자에 본인 Google 계정을 추가합니다.
        4. “사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션”을 선택하고, 승인된 자바스크립트 원본에 아래 주소를 추가합니다.
        5. 발급된 클라이언트 ID를 아래에 붙여 넣습니다.

        이 브라우저에만 저장됩니다. 모든 방문자에게 적용하려면 config.js의 googleClientId에 넣으세요.
