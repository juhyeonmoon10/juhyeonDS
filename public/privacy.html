개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 12일

juhyeonDS는 웹 브라우저에서 동작하는 DS 에뮬레이터입니다. 이 사이트는 방문자의 개인정보를 수집하거나 운영자의 서버에 저장하지 않습니다.

1. 이 사이트가 다루는 데이터

  • 게임 파일(ROM)과 세이브 파일: “이 기기에서 실행”을 쓰면 파일은 사용자의 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.
  • 자동 저장 세이브, 설정, 등록한 BIOS 파일: 사용자의 브라우저 저장소(IndexedDB, localStorage)에만 보관됩니다. 브라우저 데이터를 지우면 함께 삭제됩니다.
  • “서버에서 실행”을 선택한 경우: 게임 파일, 세이브, 조작 입력이 사용자가 지정한 에뮬레이션 서버로 전송되어 그 세션 동안 서버 메모리에서만 사용되고, 세션이 끝나면 폐기됩니다. 서버는 파일을 디스크에 저장하지 않습니다.

2. Google Drive 연동

  • 사용자가 “Google Drive 연결”을 누른 경우에만 Google 로그인을 요청합니다.
  • 요청하는 권한은 drive.file 하나입니다. 이 앱은 이 앱으로 올리거나 만든 파일만 볼 수 있으며, 사용자의 Drive에 있는 다른 파일은 읽거나 수정할 수 없습니다.
  • 이 권한은 사용자가 고른 게임 파일과 세이브 파일을 사용자 본인의 Drive “juhyeonDS” 폴더에 올리고, 목록을 보여 주고, 다시 내려받고, 사용자가 요청할 때 삭제하는 데에만 사용합니다.
  • Google 계정 정보와 Drive의 파일은 사용자의 브라우저와 Google 사이에서만 오갑니다. 운영자의 서버로 전송되거나 저장되지 않으며, 제3자에게 제공·판매하지 않고, 광고에 사용하지 않습니다.
  • 로그인 토큰은 브라우저 메모리에만 있으며 페이지를 닫으면 사라집니다.

juhyeonDS가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

3. 쿠키와 분석 도구

이 사이트는 쿠키, 광고, 방문 분석 도구를 사용하지 않습니다. 사이트는 GitHub Pages로 제공되며, GitHub는 서비스 운영을 위해 접속 기록(IP 주소 등)을 남길 수 있습니다. 자세한 내용은 GitHub의 개인정보처리방침을 참고하세요.

4. 연결 해제와 데이터 삭제

  • 사이트의 “연결 해제” 버튼을 누르거나 Google 계정의 앱 권한 페이지에서 juhyeonDS의 접근 권한을 언제든지 철회할 수 있습니다.
  • Drive에 올린 파일은 사이트의 삭제 버튼이나 Google Drive에서 직접 삭제할 수 있습니다.
  • 브라우저에 저장된 데이터는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

문의는 GitHub 저장소의 Issues로 남겨 주세요.

6. 변경
